with a period, no "Back to the library" link. Example: "Group missing@example.com was not found or its members are
not visible." The full-page banner, the admin no-access page and Trash keep the link. A toast with the request ID
replaces the line on SERVER errors; QUOTA keeps Retry disabled for 60 s.
