Inline errors (status line under a form or table, smoke 6b defect A): the error message as one sentence ending
with a period, no "Back to the library" link. Example: "Group missing@example.com was not found or its members are
not visible. Check the address." The full-page banner, the admin no-access page and Trash keep the link. A toast
with the request ID replaces the line on SERVER errors; QUOTA keeps Retry disabled for 60 s. A DENIED on an
admin-only action reads "You are no longer an admin, so nothing was changed. Ask an admin if you need access."
