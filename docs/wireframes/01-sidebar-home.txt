Search card: the input with the query, RESULTS with = rows (each template once), or
'No templates match "zzz". Try fewer words, or remove folder: and tag: from the search.'
(query cut at 60 characters, then "..."). Footer [Open library].

Tap on a row (not the button) pushes the details card: docs/wireframes/02-sidebar-prompt.txt.

Behavior (compose, slice 15)
- Insert on any row: one template.apply call, then one UpdateDraftActionResponse. The card closes (spike S6 step 0).
- Fields without a value: fallback when the variable has one, else removed, with the 4 space rules of
  ADR-0004 Amendment 2026-11-11, in body and subject. "Hi {{ask:Name}}, thanks" -> "Hi, thanks".
- Subject: D24, set only into an empty draft subject.
- Recipients: added by spec 5.7 (add, never remove; To only into an empty To). rc on the button must equal the
  counts template.apply returns; else the details card opens with the change line and nothing is inserted.
- A template address in a draft field the event does not give as a list: details card, nothing inserted.
- No notification after the insert: an insert response cannot carry one [A15, A44]. The draft is the result.
- Edit in library (details card): clears add-on cache, opens /exec?view=editor&id=... in OVERLAY, card reloads on close.

Behavior (side panel)
- Every button creates a draft that Gmail opens in a compose window; nothing changes a draft already open.
- One click for every template after S7 (D31): fields without a value are removed; the row tap opens the details card.
- Details card footer: [Create email] or [Create reply]; blank fields are removed (no notification).
- Errors: notification with the spec 7 text, no draft.
- If spike S7 fails: no action buttons; the hint moves to the top of the card.
