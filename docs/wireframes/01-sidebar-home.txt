Behavior
- Insert on a template with no prompts and all values resolved: apply in one click. Sets the body, and the subject when the template has one (D21).
- Insert on a template with prompts: push screen 2.
- Edit in library: clears add-on cache, opens /exec?view=editor&id=... in OVERLAY, sidebar reloads on close.

Behavior (side panel)
- Every button creates a draft that Gmail opens in a compose window; nothing changes a draft already open.
- One click when the template has no prompts and no recipients; otherwise the preview or prompt card first.
- Prompt card footer: [Create email] or [Create reply]; a blank field shows "Fill 1 field: <label>" and creates nothing.
- Errors: notification with the spec 7 text, no draft.
- If spike S7 fails: no action buttons; the footer hint moves to the top of the card.
